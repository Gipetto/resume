How I Use Agents

Done is defined first. I sign off on acceptance criteria before any code gets written.

Separate hands. Planning, implementing, verifying, and reviewing are different agents with narrow permissions. The reviewer checks the diff against the criteria, not the implementer’s summary.

I hold the keys. Pushes, PRs, and anything destructive wait for my approval.
